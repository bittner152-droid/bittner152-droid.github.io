shorts-factory publish

Private upload tool for the owner's own YouTube channels

shorts-factory publish is a private tool that uploads videos to the owner's own YouTube channels after manual approval. It is not offered to third parties.

What it does

  • Uploads short videos that the owner produced, together with title, description, tags and an optional publish time.
  • Uploads happen only after the owner has manually reviewed and approved each video.
  • Reads basic information about the owner's own channels and uploads to confirm that an upload succeeded.

The tool uses the YouTube Data API v3 with the scopes youtube.upload and youtube.readonly. It has no public sign-up and no other users.
